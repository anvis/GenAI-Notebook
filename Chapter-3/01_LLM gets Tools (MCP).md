
**What is MCP? **

Model Context Protocol— It is a protocol to interact with tools to fetch the data or perform certain tasks which LLM alone cannot do.

Consider it as an HTTP we previously used to have an API endpoints exposing the data but now we are using MCP Server. So anyone can startup an MCP Server and can host it.

We interact with MCP Server via a MCP Client main advantage here is our application doesn't need to maintain much logic for connectivity and connecting to multiple sources is simple basically it is same.

For Instance to Interact with SQL we used to have one kinda code, for MongoDB we had different code but with MCP it is same, just mention your connections it works.
